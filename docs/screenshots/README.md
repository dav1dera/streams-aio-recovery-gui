# Schermate del programma

Screenshot reali dell’eseguibile Windows v0.3.0, con i campi privati vuoti. Nessuna connessione alle VM, nessun backup reale e nessun esito di ripristino simulato.

Le immagini mostrano i cinque passi della procedura. Su finestre più piccole le pagine si possono scorrere; i pulsanti Indietro e Continua rimangono nel fondo della finestra.

`02-backup-v039.jpg` è una cattura reale della versione 0.3.9, con AIO manuale selezionato e il nuovo campo companion cifrato. I campi privati sono vuoti e nessuna operazione VM è stata avviata.
